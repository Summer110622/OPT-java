01 / ABOUT

最適化を、感覚ではなく
検証可能なプロセスに。

OPTjava は、Java における最適化のアイデアを実験し、比較し、共有するためのプロジェクトです。 速さだけでなく、可読性と保守性も含めて「良い最適化」を考えます。

01

Measure

まず計測する。ボトルネックを推測だけで決めない。

02

Compare

実装を比較する。トレードオフをコードとデータで確認する。

03

Improve

小さく改善する。理解できる変更を積み重ねる。

02 / PRINCIPLES

OPTjava の設計原則

01

Evidence first

改善は計測結果から始める。ベンチマークと再現性を重視します。

02

Readable by default

速さのために複雑さを無制限に増やさない。読めるコードを基準にします。

03

Small experiments

一つの仮説を小さく試し、結果を比較できる形に保ちます。

04

Open development

検証・議論・改善の履歴を GitHub 上に残し、誰でも追える形にします。
