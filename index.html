OPTjava — OPTjava は JVM・GC・メモリ・並行処理・I/O・ベンチマークを横断する、Java 最適化・高速化の百科辞典です。

[edit]最適化は、計測から始める。

Java の性能は JIT、GC、OS scheduler、I/O、依存先の状態など多数の要因で変動します。そのため、最適化は再現可能な計測条件を作るところから始めます。

  1. Baseline —

    再現可能な入力と計測条件を固定する。

  2. Profile —

    CPU・allocation・lock・I/O の支配項を特定する。

  3. Change one thing —

    仮説を一つに絞り、変更の因果を追えるようにする。

  4. Re-measure —

    性能・可読性・運用コストを含めて前後比較する。
